RDR AUTONOMOUS L2 SUPPORT HARNESS — TEST INCIDENTS
=================================================

Application: Retail Delivery Report (RDR)
Environment: Synthetic prototype / test data
Incident date for INC-001 to INC-003: November 23, 2026

PURPOSE
-------
These are user-facing incident tickets for testing the Browser, Logs, DB,
and Docs subagents and the main orchestration workflow. Root causes have
intentionally NOT been included in the tickets.

DATA COVERAGE
-------------
INC-001 through INC-006: Based on the three original VINs with matching
synthetic RDR logs and dashboard records. INC-004 through INC-006 are
alternative user reports for the same transactions as INC-001 through INC-003.
INC-007 through INC-012: Additional dashboard test records. Matching
incident-specific synthetic logs were NOT supplied for these six tickets.
The harness should report insufficient log evidence where appropriate,
not invent a root cause.
